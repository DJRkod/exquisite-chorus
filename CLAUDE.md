# Working in this repo

Five people share this repo, and not all of them use LLM agents. An agent can move faster than teammates can follow, so protect their work above all.

## Before starting work

- `git fetch` first, and check open PRs, issues and remote branches (`gh pr list`, `gh issue list`, `git branch -r`) for work that overlaps the task. If someone already owns it, stop and ask rather than build a duplicate.

## Changing code

- Work on a feature branch and open a PR. Don't push directly to `main`.
- Never force-push, rebase, or reset a branch someone else has pushed to.
- Don't delete or rewrite files, branches, or code that another person wrote unless explicitly asked. Check `git log` / `git blame` when unsure who owns something.
- Keep changes scoped to the task. Don't reformat or "clean up" other people's code in passing.

## Merging

- Merge PRs only when asked. Never merge a teammate's PR on your own.
- In a merge conflict, keep both sides' intent. If it's unclear which change should win, stop and ask.

## LLM chat log

`llm_logs_raburt3.csv` belongs to raburt3 and is regenerated by `scripts/export_llm_logs.py`. Don't edit it by hand, and don't add logging for other teammates.
