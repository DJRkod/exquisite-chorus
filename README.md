# Exquisite Chorus

A web app where musicians share unfinished musical ideas (a riff, a beat, a melody) and
invite others with the right skills to add to them. Instead of browsing everything, each
user gets a feed of projects that need what they play.

CS 409 (Fall 2026) final project. Full proposal: [docs/proposal.pdf](docs/proposal.pdf).

## Team

## Core features (MVP)

- Accounts, with each user's musical skills listed
- Start a project: upload a recording, tag it (BPM, key, genre, mood; all optional),
  and say what kind of contribution it needs
- A feed of projects matched to your skills: listen, then submit a contribution
- Track your projects; pass an amended track on to new contributors

Stretch: self-reported AI-content flags; "horizontal" Exquisite Corpse–style chaining.

## Stack

Decided in [the tech stack plan](docs/plans/2026-11-12-001-feat-tech-stack-plan.md):

- TypeScript npm workspaces: `client/` (React 19 + Vite), `server/` (Express 5 + Mongoose 9
  on MongoDB), `shared/` (API payload types)
- Auth: team-built, server-side sessions
- Audio: private S3 bucket, browser uploads and plays back via presigned URLs
- Hosting: planned as one Render web service serving both the app and the API (not
  deployed yet)

Team roles and the Nov 17 prototype tasks: [team-roles.md](team-roles.md).

## Development

Prerequisites: Node 24 (see `.node-version`).

```sh
npm install
cp .env.example .env   # then fill in values
npm run dev            # API on :3000, client on http://localhost:5173 (proxies /api)
npm test               # vitest in client and server
npm run lint           # oxlint
npm run typecheck      # tsc in every workspace
npm run build          # client bundle + server compile
npm run seed -- --in-memory   # demo data (prototype content) in a throwaway database
```

`npm run seed` without `--in-memory` seeds the database in `MONGODB_URI`. Demo data:
the prototype's people and projects; sign in as `riley@example.com` with
`chorus-demo-2026` (see `server/src/models/seed.ts`).

Deployment and cloud setup (AWS S3 + budget alert, MongoDB Atlas, Render): see [docs/setup.md](docs/setup.md).
