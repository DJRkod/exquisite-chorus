# Exquisite Chorus

A web app where musicians share unfinished musical ideas (a riff, a beat, a melody) and
invite others with the right skills to add to them. Instead of browsing everything, each
user gets a feed of projects that need what they play.

CS 409 (Fall 2026) final project. Full proposal: [docs/proposal.pdf](docs/proposal.pdf).

## Team

Zachary McKinney · Zed Suarez · Nalin Tiwary · Raymond Burt · Srinath Venkatesh

## Core features (MVP)

- Accounts, with each user's musical skills listed
- Start a project: upload a recording, tag it (BPM, key, genre, mood; all optional),
  and say what kind of contribution it needs
- A feed of projects matched to your skills: listen, then submit a contribution
- Track your projects; pass an amended track on to new contributors

Stretch: self-reported AI-content flags; "horizontal" Exquisite Corpse–style chaining.
